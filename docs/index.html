SwiftMesh

Open local 3D models. Inspect. Record a turntable.

A Windows desktop app for viewing .glb, .gltf, and .obj files — inspect scene data and export a one-revolution turntable video.

Download for Windows View on GitHub

Features

Built for local model work

No cloud uploads. Open files from disk, inspect what is inside, and capture a clean turntable clip.

  • Open local models

    File → Open, drag-and-drop, or Open Recent. Remote URL and cloud loading are not included.

  • Inspect the scene

    Multi-tab viewing with hierarchy, textures, materials, geometries, and model info panels.

  • Record a turntable

    One-revolution clips in MP4 or WebM, with size and quality presets. MP4 uses bundled ffmpeg.

  • Preferences that fit

    Appearance themes, lighting, recording folder, performance options, English / 中文, and optional auto-update.

Formats & requirements

What you need

Install the latest Windows NSIS build from Releases. Portable builds may appear in some releases; in-app auto-update targets the NSIS install.
