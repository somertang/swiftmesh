Features

Built for local model work

No cloud uploads. Open files from disk, inspect what is inside, and capture a clean turntable — as video or stills.

Work across local models

Keep files on disk. Open several at once, with camera controls that stay out of the way.

  • File → Open, drag-and-drop, or Open Recent
  • Tabs and split panes for side-by-side work
  • Perspective or orthographic camera

See what the file contains

Inspect the scene, then mark notes and distances on the mesh itself.

  • Hierarchy, textures, materials, geometries, and info
  • Annotate on the model, ground, or view plane
  • Measure two points — overlay lines stay visible

One revolution, video or stills

Capture a clean turntable for review, the web, or an asset pipeline.

  • Video as MP4 or WebM
  • Frame sequences and spritesheet atlases
  • Optional multi-axis batch and camera projection
