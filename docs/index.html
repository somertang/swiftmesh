Features

Built for local model work

No cloud uploads. Open files from disk, inspect what is inside, and capture a clean turntable clip.

Open & multi-tab

File → Open, drag-and-drop, or Open Recent. Work across multiple models with camera controls that stay out of the way.

Inspect panels

Hierarchy, textures, materials, geometries, and model info — see what the file actually contains.

Turntable recording

Export one-revolution clips with size and quality presets. MP4 uses bundled ffmpeg; WebM is available too.

Turntable output preview

Preferences that fit

Themes, lighting, recording folder, performance options, English / 中文 UI, and optional auto-update from Releases.

Model Theme

Choose how the viewport presents your model: a light studio look, or a darker professional stage with floor grid and a navigation gizmo.

Formats & requirements

What you need

Install the latest Windows NSIS build from Releases. Portable builds may appear in some releases; in-app auto-update targets the NSIS install.
