Inspect

Know what is inside your model

Review the scene structure, textures, materials, geometry, and summary data beside the viewport.

  • Search the hierarchy and select or hide scene nodes
  • Preview textures, materials, geometry, and model statistics
  • Add visible notes and two-point measurements

Turntable output preview

Present

Turn your model into a review-ready turntable

Start capture from the viewport and export one complete revolution using your saved size, quality, and output settings.

  • MP4 or WebM video
  • Frames or spritesheet atlases
  • Multi-axis still capture

Protected sharing

Add protection before you share

Package a model with a password or export a watermarked copy without uploading it to a service.

Password-protect a model package

Package the model and its companion files into an encrypted SMSH file. Recipients open it in SwiftMesh using a password you send separately.

  • Password protection
  • Permission limits
  • Custom expiry

Designed to discourage casual access—not as hard DRM.

Export a watermarked copy

Add a text or image stamp, preview it on the model, and export a new GLB or GLTF copy without overwriting the source.

  • Text or image
  • Live preview
  • New export copy

The original model remains unchanged.

Features

More tools for everyday model work

Compare models, annotate details, reduce static meshes, convert formats, and preview animation—all locally.

Local files

Open from File, drag and drop, or Open Recent.

Tabs & split view

Keep several models open and compare them side by side.

Annotate & measure

Mark details and measure two points directly in the viewport.

Reduce static meshes

Preview a lower-density mesh and export it as a new GLB.

Convert formats

Convert GLB ↔ GLTF, OBJ → GLB, or FBX → GLB.

Preview animation

Play and scrub animation clips included in glTF and FBX files.

Themes

Choose the viewport that fits the task

Use a clean light studio for focused viewing or a professional dark viewport with a floor grid and navigation gizmo.
